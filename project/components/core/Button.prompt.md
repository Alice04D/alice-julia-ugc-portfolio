Pill-shaped call-to-action button. Use for primary actions (Book Now, Enquire) and secondary nav CTAs.

```jsx
<Button variant="primary" size="lg" iconRight>Book a call</Button>
<Button variant="outline">View portfolio</Button>
```

Variants: `outline` (default, transparent with ink border, fills solid ink on hover) and `primary` (solid ink, deepens to accent rose on hover). Both scale up slightly on hover — never instant, always the 340ms eased transition.
